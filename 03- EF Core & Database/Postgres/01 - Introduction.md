## What is DB?
بنحتاج الـ DB عشان نعمل **Persistence** للـ **Data** بتاعت الأبلكيشن وبتديك الـ **CRUD Operations** عليها و **Relations** بين الـ Tables وبعض
****
## Disk-based Systems
ببساطة الداتا بتتخزن في كذا مكان هنتكلم عن مكانين الـ 
- Primary Memory
- Secondary Memory (Disks)
أكيد عارفين أن الرامات أسرع من الـ SSD بس في نفس الوقت الرامات أغلى بكتير وفي أزمة عالمية وكل ده، فلو اعتمدنا أننا نخزن الداتا فيها هيبقى شيء مكلف جدا

فالكوكب كله بيستعمل الـ Disk-based في تخزين المعلومات اه هيكون السرعة أقل والـ `fetch` أصعب بس هنوفر فلوس كتير 

طب ماشي أحنا عرفنا نخزن المعلومات فين بس هي الـ DB مش مجرد أننا بنخزن وخلاص ده عشرات من الطبقات المعقدة مين مسئول عنها؟
****
## DBMS 
دي إختصار لـ **Database Management System** وده السوفتوير المسئول عن الإدارة الكاملة للـ DB سواء 
- Organization Data
- Integrity 
- Security
- Data Access
بس هو ليه بنحتاج الـ **DBMS**؟
ما احنا كنا بنخزن الداتا في `TXT` فايلز وخلاص بس لما بتخزن في txt بتظهر مشاكل كتير لما تعمل **Parsing** مثلا للداتا عشان تنقلها وهكذا بتظهر مشاكل وبتبقى عملية بطيئة ومكلفة
ومفيش أي **Structure** الدنيا عشوائية مفيش أي نظام بأي شكل

وبردو هتظهر مشكلة في الـ **Concurrency** لو اتنين دخلوا في نفس اللحظة لنفس الداتا يعدلوها مين هيدخل الأول 
****
## SQL vs NoSQL
الداتا بيز نوعين 
- **Relational DB**
بتـ Organize الداتا في Tables و Columns وهكذا بتكون عامل Schema ومنظم الدنيا وموحد كل حاجة

فبقى في مميزات مهمة زي Data Integrity وأن الداتا بتكون منظمة بشكل واضح 

في أنواع كتير زي MySQL و PostgreSQL و SQL Server
- **Non- Relational DB**
هنا بتعمل **Collections** و الـ ROW بيتسمى **Document** وكل دوكومينت ممكن يكون مختلف عن التاني 

هي Flexible فعلا ومفيش أي تحكم عليك بس طبعا دي عشوائية بحتة

مفيدة في حالة أنك عايز تعمل `CMS` يعني لو عايز تضيف مقال مش كل شوية هتروح تعدل في الكود وترفعه على جيتهاب عشان المقال يظهر بتستخدم خدمة مثلا زي **Sanity**
****
